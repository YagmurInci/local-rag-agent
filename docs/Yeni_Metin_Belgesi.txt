# API Ağ Geçidi Zaman Aşımı ve Veritabanı Yeniden Bağlantı Kılavuzu

## 1. Kritik Sistem Uyarısı
- Veritabanı havuzu bağlantı sayısı maksimum limite (%95) ulaştığında tüm yeni istekler 504 Gateway Timeout hatası verir.
- Veritabanı ana servisini doğrudan kapatmak yerine önce bağlantı havuzunu kademeli boşaltın.

## 2. Sorun Giderme Adımları
1. Sunucu terminaline bağlanıp aktif bağlantı sayısını kontrol edin: `netstat -an | grep 5432`.
2. Bekleyen sorguları ve kilitli işlemleri sonlandırmak için `kill_idle_connections()` komutunu çalıştırın.
3. Express API servisinin ortam değişkenlerindeki bağlantı havuzu limitini (POOL_SIZE) 50'ye yükseltin.
4. Servisi kesintisiz olarak yeniden yükleyin: `npm run reload:graceful`.
5. Hata loglarını izleyerek yanıt süresinin 200 ms altına indiğini doğrulayın.
